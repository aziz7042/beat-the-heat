# Beat the Heat

A 2D Godot platformer built around heat management. The player crosses a hot environment, avoids lava, uses shade to recover and collects water bottles before reaching the exit.

## Features

- Responsive horizontal movement and jumping
- Heat resource with environmental pressure
- Water-bottle pickups that restore the resource
- Lava hazards and shade zones
- Win, game-over and restart states
- Character animation and layered sound effects

## Technology

`Godot 4.6` · `GDScript` · `2D physics` · `Signals` · `Audio`

## Run

Open `project.godot` in Godot 4.6 or a compatible Godot 4 release, then run the main scene.
